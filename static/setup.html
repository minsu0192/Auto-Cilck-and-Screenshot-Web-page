2단계 · 선택

외부에서도 접속할까요?

집 밖(LTE/5G/다른 Wi-Fi)에서 접속하려면 ngrok 토큰이 필요해요. 같은 Wi-Fi 안에서만 쓸 거면 건너뛰어도 돼요.

ngrok 토큰 받는 법
  1. ngrok.com 가입 (이메일/구글 계정, 무료)
  2. 대시보드 → Your Authtoken
  3. 토큰 복사 → 아래 칸에 붙여넣기
3단계 · 선택

알림을 받을까요?

서버 시작/외부 URL 변경 시 텔레그램으로 알림을 보내드려요. 필요 없으면 건너뛰세요.

봇 만드는 법
  1. @BotFather 열기 → /newbot 입력
  2. 봇 이름 → 사용자명(...bot으로 끝나야 함)
  3. 받은 토큰을 "봇 토큰"에 붙여넣기
  4. 봇한테 아무 메시지나 보낸 후 테스트 버튼 클릭 → 자동으로 Chat ID 가져옴
