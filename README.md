# macOS 웹 기반 원격 데스크탑

브라우저만으로 macOS 화면을 보고 마우스/키보드를 원격 조작할 수 있는 웹앱입니다.

집 Mac에서 서버를 실행하면, 외부 PC나 모바일에서 브라우저로 접속하여 화면을 보고 조작할 수 있습니다.
**별도 프로그램 설치 없이 브라우저만 있으면 됩니다.**

## 주요 기능

### 화면 & 조작
- **실시간 화면 캡처** — JPEG 스트리밍, 화질·해상도·갱신 속도 조절
- **마우스** — 클릭, 더블클릭, 우클릭, 드래그앤드롭, 스크롤
- **키보드** — 단축키 조합 (Cmd+C, Cmd+V 등), 한글 입력 지원
- **반응형** — 데스크탑/모바일 자동 최적화

### 모바일 특화
- **터치 제스처** — 탭=클릭, 길게 누르기=우클릭, 스와이프=스크롤, 드래그=드래그
- **입력 바** — 한글 IME 깨짐 없이 텍스트 입력 + 검색창 Enter 한 번에
- **퀵 키 패드** — Cursor/VSCode 다이얼로그의 OK·취소·화살표를 한 번에

### 외부 접속 & 알림
- **ngrok 자동 실행** — 서버 시작 시 외부 접속 URL 자동 생성
- **세션 복구** — ngrok 끊김 자동 감지 → 재연결 → 새 URL 텔레그램 전송
- **텔레그램 알림** — 접속 URL을 휴대폰으로 즉시 받기

### 보안
- 비밀번호 인증 + 24시간 세션 토큰 (변경 가능)
- 5회 로그인 실패 시 IP 10분 잠금
- 타이밍 공격 방지 (`secrets.compare_digest`)
- 접속 로그 파일 기록 (`access.log`)

## 빠른 시작

### 방법 1: macOS 앱으로 설치 (추천 — 터미널 필요 없음)

```bash
cd remote-desktop
./build_app.sh
```

이렇게 한 번만 빌드하면 `~/Applications/RemoteDesktop.app`이 생성됩니다.

이후로는:
- **Spotlight (Cmd+Space)** → "Remote Desktop" 검색 → Enter
- 또는 **Launchpad** → Remote Desktop 클릭
- 또는 **Finder** → 응용 프로그램 → 더블클릭

앱이 자동으로:
1. 의존성 설치 (필요 시)
2. `.env` 생성/검증 (비밀번호 미설정이면 텍스트 편집기로 열어줌)
3. 서버 시작
4. 브라우저 자동 오픈
5. 알림 센터에 시작 메시지 표시

종료하려면 Dock의 아이콘 우클릭 → 종료.

### 방법 2: 터미널에서 한 번에 실행

```bash
cd remote-desktop
./start.sh
```

`start.sh`가 자동으로 처리하는 것:
1. Python3 설치 확인
2. 의존성 설치 (`pip install -r requirements.txt`)
3. `.env` 파일 자동 생성 (없으면 `.env.example`에서 복사)
4. 비밀번호 설정 안내
5. 서버 시작

> 첫 실행 시 `.env`가 생성되고 종료됩니다. `nano .env`로 PASSWORD를 변경한 후 `./start.sh`를 다시 실행하세요.

### 수동 설치

```bash
pip install -r requirements.txt
cp .env.example .env
# .env 파일을 열어 PASSWORD 설정
python server.py
```

서버가 시작되면 콘솔에 다음과 같이 표시됩니다:

```
==================================================
  macOS Remote Desktop Server
==================================================
  로컬:  http://localhost:8000
  외부:  https://xxxx-xxx-xxx.ngrok-free.app
  알림:  텔레그램 활성화
==================================================
```

## macOS 권한 설정 (필수)

서버가 화면을 캡처하고 마우스/키보드를 제어하려면 macOS 권한이 필요합니다.

### 1. 화면 기록 권한
**시스템 설정** → **개인정보 보호 및 보안** → **화면 기록** → 사용하는 터미널 앱 추가 후 **허용**

### 2. 손쉬운 사용 권한
**시스템 설정** → **개인정보 보호 및 보안** → **손쉬운 사용** → 사용하는 터미널 앱 추가 후 **허용**

> ⚠️ 권한 변경 후 터미널을 **완전히 종료하고 재시작**해야 적용됩니다.
> Cursor, VSCode 통합 터미널 등에서 실행할 경우 해당 앱에 권한을 부여하세요.

## 환경 변수 설정

`.env` 파일에서 설정합니다:

```bash
# ─── 필수 ───
PASSWORD=나만의안전한비밀번호      # 로그인 비밀번호 (반드시 변경)

# ─── 서버 설정 ───
PORT=8000                       # 서버 포트
TOKEN_EXPIRE_HOURS=24           # 로그인 유효 시간 (시간 단위)

# ─── 외부 접속 (선택) ───
NGROK_AUTHTOKEN=                # ngrok 인증 토큰

# ─── 텔레그램 알림 (선택) ───
TELEGRAM_BOT_TOKEN=             # 텔레그램 봇 토큰
TELEGRAM_CHAT_ID=               # 텔레그램 채팅 ID
```

> 🚨 `PASSWORD`가 비어있거나 `admin`, `password`, `1234` 같은 약한 값이면 서버가 시작되지 않습니다.

## 외부 접속 (ngrok)

`NGROK_AUTHTOKEN`을 설정하면 서버 시작 시 자동으로 ngrok 터널이 생성되고, 외부 URL이 콘솔과 텔레그램에 표시됩니다.

### 설정 방법

1. [ngrok.com](https://ngrok.com) 가입 (무료)
2. 대시보드 → **Your Authtoken** 복사
3. `.env`에 입력:
   ```
   NGROK_AUTHTOKEN=2abc1234567890_xxxxxxxxxxxxxxx
   ```
4. `./start.sh` 실행 → 자동으로 외부 URL 생성

ngrok을 사용하지 않으려면 `NGROK_AUTHTOKEN`을 비워두세요 (로컬 전용 모드).

### 자동 재연결

ngrok 무료 플랜은 8시간 후 세션이 만료됩니다. 서버는 30초마다 터널 상태를 확인하여:
- 끊김 감지 → 자동 재시작
- 새 URL 생성 → 텔레그램으로 즉시 전송

## 텔레그램 알림

서버 시작/종료/ngrok 재연결 시 텔레그램으로 알림을 받습니다.

### 1단계: 봇 만들기

1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` 입력
3. 봇 이름 입력 (예: `내 원격 데스크탑`)
4. 봇 사용자명 입력 (예: `my_desktop_bot` — 반드시 `bot`으로 끝나야 함)
5. BotFather가 주는 토큰 복사 → `.env`에 입력:
   ```
   TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ```

### 2단계: Chat ID 확인

1. 방금 만든 봇을 텔레그램에서 검색하여 **아무 메시지나 보내기** (예: `hello`)
2. 브라우저에서 다음 URL 접속 (토큰 부분만 교체):
   ```
   https://api.telegram.org/bot[받은토큰]/getUpdates
   ```
3. 응답 JSON에서 `"chat":{"id":123456789}` 찾기 → 그 숫자가 Chat ID
4. `.env`에 입력:
   ```
   TELEGRAM_CHAT_ID=123456789
   ```

### 알림 종류

| 이벤트 | 알림 |
|--------|------|
| 서버 시작 | 🖥 접속 URL + 시작 시각 |
| ngrok 세션 만료 → 재연결 | 🔄 새 접속 URL |
| 서버 종료 | ⚠️ 종료 시각 |

## 사용 방법

브라우저에서 서버 URL 접속 → 비밀번호 입력 → 원격 화면 표시

### 툴바 구성

```
[● 연결됨] [갱신:1.0s] [화질:50] [해상도:50%] [키보드] [드래그] [우클릭] [퀵키]
```

- **상태 점** — 초록(연결) / 노랑(로딩) / 빨강(끊김)
- **갱신** — 스크린샷 갱신 간격 (200ms~5초)
- **화질** — JPEG 압축률 (10~100, 낮을수록 빠름)
- **해상도** — 25% / 50% / 75% / 100% (낮을수록 빠름)

### 데스크탑 조작

| 동작 | 방법 |
|------|------|
| 클릭 | 화면 클릭 |
| 더블클릭 | 화면 더블클릭 |
| 우클릭 | 마우스 우클릭 또는 "우클릭" 버튼 → 클릭 |
| 스크롤 | 마우스 휠 |
| 드래그앤드롭 | "드래그" 버튼 활성화 → 마우스 드래그 |
| 키보드 | "키보드" 버튼 또는 ESC → 키 입력 |
| 단축키 | 키보드 모드에서 Cmd+C, Cmd+V 등 자유롭게 |

> 브라우저 단축키(Cmd+W, Cmd+T, Cmd+R 등)는 차단되지 않습니다.

### 모바일 조작

| 동작 | 방법 |
|------|------|
| 클릭 | 터치 탭 (햅틱 진동) |
| 우클릭 | 길게 누르기 (0.5초, 강한 진동) 또는 "우클릭" 버튼 → 탭 |
| 스크롤 | 위/아래 스와이프 |
| 드래그앤드롭 | "드래그" 버튼 → 터치 드래그 |
| 키보드 | "키보드" 버튼 → 입력 바 + 가상 키보드 등장 |
| **줌인/줌아웃** | **두 손가락 핀치** (1배~5배) |
| **팬 (이동)** | **줌인 상태에서 두 손가락 드래그** |
| **줌 리셋** | **줌인 상태에서 더블탭** 또는 핀치아웃 |

### 📱 홈 화면에 추가 (PWA — 진짜 앱처럼)

iOS Safari나 Android Chrome에서 **"홈 화면에 추가"**를 하면 브라우저 주소창 없이 전체화면 앱처럼 실행됩니다.

**iOS Safari**:
1. 서버 URL에 접속
2. 하단 공유 버튼 → **홈 화면에 추가**
3. 이름 확인 후 **추가**
4. 홈 화면의 "Remote" 아이콘 → 전체화면 앱으로 실행

**Android Chrome**:
1. 서버 URL에 접속
2. 우상단 메뉴 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 실행

PWA 모드의 장점:
- 브라우저 주소창 숨김 → 화면 더 넓게
- 앱 아이콘으로 빠른 실행
- 한 번 로그인하면 토큰 자동 저장 → **새로고침해도 다시 로그인 불필요**

### 단축키 패드 (모바일에서 macOS 단축키 한 번에)

툴바의 **"단축키"** 버튼 → 화면 좌하단에 자주 쓰는 단축키 패드 표시:

| 키 | 동작 |
|---|------|
| ⌘C / ⌘V / ⌘X | 복사 / 붙여넣기 / 잘라내기 |
| ⌘Z | 실행취소 |
| ⌘A | 전체선택 |
| ⌘S | 저장 |
| ⌘F | 찾기 |
| ⌘Tab | 앱 전환 |
| ⌘Space | Spotlight |
| ⌘\` | 같은 앱 윈도우 전환 |

### 전체화면 모드

툴바의 **"전체화면"** 버튼으로 브라우저 전체화면 진입.

> iOS Safari는 전체화면 API를 지원하지 않으니 PWA(홈 화면에 추가)를 사용하세요.

### 입력 바 (키보드 모드 ON 시 화면 하단 표시)

한글 IME 깨짐을 방지하기 위해, **글자를 입력 바에 모은 후 한 번에 전송**하는 방식입니다.

```
┌───────────────────────────────────────────┐
│ [Tab] [입력칸: 안녕하세요  ] [⌫] [전송]   │
└───────────────────────────────────────────┘
```

| 버튼 | 동작 |
|------|------|
| **입력칸** | 텍스트 입력 (한글/영어/특수문자 모두 지원, IME 정상 작동) |
| **전송** | 입력 바의 텍스트를 맥에 붙여넣음 (클립보드 + Cmd+V) |
| **가상 키보드 Enter** | 텍스트 전송 + Enter 키 → 검색창에서 한 번에 검색 실행 |
| **Tab** | Tab 키 전송 (입력 바 텍스트가 있으면 먼저 전송 후) |
| **⌫ (Backspace)** | 입력 바에 글자가 있으면 그 글자만 지우고, 비어있으면 맥에서 Backspace 실행 |

#### 사용 예시: 모바일에서 네이버 검색

1. 모바일 브라우저로 원격 데스크탑 접속
2. 맥 화면의 네이버 검색창 위치를 **탭** → 검색창 포커스
3. 툴바 **"키보드"** 탭 → 입력 바와 가상 키보드 등장
4. 입력 바에 `"날씨"` 입력
5. 가상 키보드 **Enter** → "날씨" 전송 + Enter → 검색 실행 ✅

### 퀵 키 패드

다이얼로그 응답이나 자주 쓰는 키를 한 번의 탭으로 보낼 수 있습니다.

툴바의 **"퀵키"** 버튼 → 화면 우하단에 패드 표시:

```
   ⏎     ← Enter (확인/OK)
   Esc   ← ESC (취소)
  ┌───┐
  │ ↑ │
  │←␣→│  ← 화살표 + Space
  │ ↓ │
  └───┘
```

| 키 | 용도 |
|---|------|
| **⏎ Enter** | Cursor/VSCode/macOS 다이얼로그의 OK 버튼 |
| **Esc** | 다이얼로그/메뉴 취소 |
| **↑ ↓ ← →** | 자동완성 후보 선택, 커서 이동 |
| **␣ Space** | 페이지 스크롤, 체크박스 토글 |

#### 사용 예시: Cursor 권한 다이얼로그

1. Cursor가 "Allow this command?" 다이얼로그 표시
2. 모바일에서 **퀵키** 버튼 ON (아직 안 켰다면)
3. 화면 우하단 **⏎** 한 번 탭 → 확인 완료 ✅

> 키보드 모드를 켜지 않아도 퀵키 패드만 따로 사용할 수 있습니다.

## 보안

### 인증
- 비밀번호 + 세션 토큰 방식 (`secrets.token_hex(32)`)
- `secrets.compare_digest`로 타이밍 공격 방지
- 토큰은 메모리에만 저장 (서버 재시작 시 모두 무효화)

### Rate Limiting
- 5회 로그인 실패 → 해당 IP 10분 잠금
- 모든 로그인 시도는 `access.log`에 기록 (성공/실패, IP, 시각)

### 권장 사항
- ✅ 강력한 비밀번호 사용 (16자 이상, 대소문자+숫자+특수문자)
- ✅ ngrok URL은 절대 공개하지 마세요
- ✅ 서버를 사용하지 않을 때는 종료
- ❌ `PASSWORD=admin`, `password`, `1234` 같은 약한 값 금지 (서버가 거부함)

## 성능 한계

이 앱은 HTTP 폴링 + JPEG 스트리밍 방식이므로 VNC/RDP 같은 부드러움은 어렵습니다.

| 환경 | 예상 FPS | 비고 |
|------|---------|------|
| 동일 LAN | 2~3 FPS | 화질 50, 해상도 50% 기준 |
| ngrok 외부 | 1~2 FPS | 네트워크 지연 포함 |

### 더 빠르게 보고 싶을 때
- 갱신 슬라이더를 200~500ms로 낮추기
- 해상도를 25%로 낮추기
- 화질을 20~30으로 낮추기

### 동작 후 즉시 갱신
클릭/스크롤/키 입력 후에는 자동으로 한 번 더 갱신을 트리거합니다 (`scheduleRefresh`).

|--------|------|------|
| GET | `/` | `/static/index.html`로 리다이렉트 |

## 문제 해결

### "권한이 없습니다" 또는 화면이 검은색

→ macOS 화면 기록 권한이 없는 경우. [권한 설정](#macos-권한-설정-필수)을 참고하여 터미널 앱에 권한을 부여하고 터미널을 재시작하세요.

### "비밀번호 오류" 5회 후 로그인 안 됨

→ IP가 10분간 잠금된 상태입니다. 10분 기다리거나 서버를 재시작하세요.

### ngrok URL이 텔레그램에 안 옴

→ `.env`의 `TELEGRAM_BOT_TOKEN`과 `TELEGRAM_CHAT_ID`를 확인하세요. 봇에게 한 번 이상 메시지를 보낸 후 Chat ID를 다시 확인합니다.

### 모바일에서 한글이 깨져 입력됨

→ 가상 키보드의 일반 키가 아니라 **입력 바**를 사용하세요. 키보드 모드를 켜면 화면 하단에 입력 바가 표시됩니다.

### 화면이 너무 끊김

→ 갱신 슬라이더를 300ms 이하로, 해상도를 25%로 낮춰보세요. 동일 LAN에서는 800Mbps 이상의 Wi-Fi가 좋습니다.

### Cursor/VSCode 다이얼로그에 응답이 어려움

→ 툴바의 **"퀵키"** 버튼을 켜면 화면 우하단에 Enter/Esc/화살표 패드가 떠서 한 번에 응답할 수 있습니다.

### 서버가 시작 시 "비밀번호가 비어있어 시작할 수 없습니다"

→ `.env` 파일을 열어 `PASSWORD=`에 값을 설정하세요. `admin`, `password`, `1234`는 거부됩니다.
